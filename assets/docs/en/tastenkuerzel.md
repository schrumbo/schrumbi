# Shortcuts

All shortcuts as they are currently set. You can change them in {key:OpenSettings} → {ui:Tastenkürzel}. {key:ShowShortcuts} shows them as an overview.

## Everywhere

| Command | Shortcut |
|---|---|
| {ui:Befehl suchen…} | {key:CommandPalette} |
| {ui:Schrumbi-Anleitung} | {key:ShowHelp} |
| {ui:Tastenkürzel anzeigen} | {key:ShowShortcuts} |
| {ui:Einstellungen} | {key:OpenSettings} |
| {ui:Datei schnell öffnen} | {key:quickOpen} |
| {ui:In allen Dateien suchen} | {key:searchFiles} |
| {ui:Neuer Eintrag} | {key:newEntry} |
| {ui:Neue Notiz, Datei oder Ordner} | {key:newFile} |
| {ui:Tagesnotiz öffnen} | {key:dailyNote} |
| {ui:Jetzt synchronisieren} | {key:syncNow} |
| {ui:Aktualisieren} | {key:refresh} |
| {ui:In Obsidian öffnen} | {key:openInObsidian} |
| {ui:Rückgängig} | {key:Undo} |
| {ui:Anderen Ordner öffnen…} | {key:openOtherWorkspace} |
| {ui:Details ein-/ausblenden} | {key:toggleInspector} |
| {ui:KI ein-/ausblenden} | {key:toggleAi} |

{key:Undo} also takes back {ui:Umbenennen}, {ui:Verschieben} and {ui:Ablegen} in a note once there is nothing left to undo in the text. While a window such as {ui:Neuer Eintrag} is open, the other shortcuts do nothing.

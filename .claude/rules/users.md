# Users

Schrumbi is built for five archetypes, derived with sources in `.claude/archetypes.md`. Read it before designing a feature, a flow or a remake.

| | Archetype | Share | Test with |
|---|---|---|---|
| A | Deadline Juggler: Windows, mouse, no Markdown, German, reactive | ~40–45 % | mouse only, everyday German, one undo |
| B | Formula Writer: LaTeX math, PDF beside note, PDF export | ~20 % | typing speed, math correctness, keyboard path |
| C | Card Crammer: Anki, thousands of cards, exam dates | ~10–15 % | review speed, lossless import, no overdue wall |
| D | Restarter: overwhelmed, ADHD or anxiety, abandons tools | ~15 % | one next step, zero setup, nothing nags |
| E | Vault Veteran: Obsidian, git, keyboard, big vaults | ~5–10 % | files untouched, palette + shortcut, 20k notes |

A is the default user. Nothing may require being B or E to use the basics; nothing may cap what B and E can do.

- Basics work with zero configuration. Settings refine; they never unlock the core.
- Defer, never remove: Markdown source, graph, queries, git, statistics and shortcut config appear on first use or opt-in.
- Every command has a mouse path and a palette entry plus shortcut, and menus and tooltips show the shortcut.
- Default paths use everyday German. No "Vault", "Commit", "Frontmatter", "Konvention" unless the user opted into that feature.
- Nothing nags, blames or shows red walls. Progress is framed as done, not missed. Suggestions are offered once, quietly, and dismissable.
- Files the user did not ask to change stay byte-identical and readable by Obsidian.
- Windows quality counts as much as macOS.

Requests that only the anti-persona wants (team workspaces, plugin API, cloud accounts, mobile-first) are declined by default.

- **PDF highlights sit under the text.** Marks are blended into the page, so letters stay crisp in every colour, light and dark.
- **Edit PDF pages.** Rotate, delete, reorder by drag or Alt+arrow, and insert pages from other PDFs in the PDF-Seiten list. The file changes in place, one undo brings it back byte for byte, and your marks follow their pages.
- **Pen, eraser and notes.** Draw on any page in four colours and two widths (P, E), pin notes anywhere (N), or add a note to a highlight. The Marker panel lists them all and is fully keyboard-driven.
- **Mit Markierungen exportieren** writes a copy with your highlights, notes and drawings as real PDF annotations, readable in any PDF viewer. The original stays untouched.
- **Marks survive sync and git.** Notes, pins and drawings live in a separate file next to the old one, changes from outside reload on their own, and merges keep both sides. A file the app cannot read is locked, never overwritten.
- **Typed notes are never lost**, also when the PDF reloads, the folder changes or the app quits while a note is open.

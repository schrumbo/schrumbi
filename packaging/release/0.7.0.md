- **Designs from files.** Load a design via Einstellungen → "Design laden…". A few ready-made designs are in the repository's `themes/` folder. Nord and Dracula stay built in.
- **Fast with big folders.** Saving a note in a folder with 20,000 notes no longer re-reads the whole folder. Search and quick open run beside the window, so typing never waits. Typing in very long lines stays fast, images use at most about 450 MB, and an idle window no longer redraws for the blinking caret.
- **Safer data.** Settings changed in two windows at once no longer get lost. A note changed in another app waits for your decision before undo touches it, and a design file is never overwritten. Sync never replaces the other device's app data. Anki imports keep new cards new, and undoing one removes the empty folders it made.
- **Fewer crashes.** Dates around the clock change, calendar files with repeat rules, huge PDF pages and very large quick-add numbers no longer crash or misplace entries.
- **Keys and focus.** Keys reach the app after dialogs and clicks. The command palette opens with Ctrl+P, Ctrl+K stays the link key. Undo in a note works across the source and preview view. Emoji, flags and accented letters stay whole when you move or delete.
- **Files and media.** CSV and TSV files open as a table with a switch to plain text. Audio previews show WAV files and their length. Enter in the top search opens the hit with the caret at its start.
- **Safer AI.** The AI never reads hidden folders or app files without asking, asks once per note for changes today, and every change it writes is one undo step.
